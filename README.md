## 확정 기준

모바일 우선, 화이트·블루, 사용자 PROCESS 현황 및 관리자 회원별 운영. 채팅·캐릭터·이벤트·문의·커뮤니티 제외.
아이디·비밀번호·이름·전화번호 가입 후 관리자 승인. 이메일 없이 관리자 비밀번호 재설정 지원.
기간 1시간~30일 또는 기간 미정. 24시간, 3분 반영, 현재 평가금액 기준. 수익·손실 방향 확률 85/15.
기간형은 시작 시 30일 순수익 +800~1200% 목표 추첨 후 기간별 복리 환산. 관리자 기간·목표 개별 설정 가능.
기간 미정은 별도 하루 순수익 목표 +25~30%. 초기 모듈에서는 시작 시 하루 목표를 한 번 추첨해 저장.
목표 추종 내부 시뮬레이션이며 실제 거래 수익이나 목표 달성을 보장하지 않습니다.
정상·조기 종료 모두 현재 금액 그대로 종료. 강제 차액 반영 없이 관리자 전용 차액 기록.

## 구현 상태

순수 계산 기반과 테스트 9건 통과(Node 24). `npm test`로 실행.
인증·DB·RPC·원장·실제 자동 실행·사용자/관리자 UI·배포는 후속 구현 대상입니다.
trackingHint는 계산 힌트이며 수익·손실 금액 산출 엔진은 아닙니다.
관리자 기록 객체 분리는 접근 통제 구현을 대신하지 않습니다.
