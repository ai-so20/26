# 이름 없는 AI 프로세스 — 서버 보호형 이식

원본: 2026-10-01 AI-main 코드. 원본 저장소 수정 없음.

## 보호 모델
- 기존 관리자·회원 페이지의 HTML은 `private-pages/`에 서버 코드로 보관; 비로그인 방문자에게 대시보드/관리자 HTML 제공 금지.
- 데이터 조회·변경은 서버 전용 `/api/secure`만 사용. 원본 브라우저 Supabase 클라이언트/공개 키를 제거.
- 서버 DB 접근은 서비스 전용 키. `app_*` 테이블 RLS ON, `anon` 및 `authenticated` 테이블/함수 GRANT 철회.
- 서버 검증 세션: HMAC 서명 + HttpOnly/SameSite=Strict 쿠키, 서버에서 매번 계정 상태 재확인.
- 기존 스타일/마크업을 최대한 보존하되 레거시 로그인 스크립트를 교체.
- 기본 자동지급은 안전하게 OFF. 운영 검증 후 활성화.
- 기존 GitHub 26 공개 저장소를 Private으로 전환해야 소스 자체 비공개가 됩니다.

## 구현/검증 제한
- 기존 페이지의 모든 UI 경로에 대한 브라우저 종단 간 테스트 미완료.
- Vercel 환경변수 `SUPABASE_URL`, `SUPABASE_SECRET_KEY`, `SESSION_SECRET` 필수.
- 사용자/관리자 신규 비밀번호는 bcrypt 해시로 저장. 이전 평문 비밀번호와 호환되지 않음.
- 원본 서비스의 회원 데이터는 이 프로젝트에 이식하지 않음(초기화된 26 테스트 공간).

## 알려진 추가 작업
- 장기 세션 로그, 관리자 변경 감사 로그, MFA, UI 전체 회귀 테스트
- 회원 가입은 비활성화: 관리자 등록만 허용 (`/api/admin/member`).
- 기존 수익 처리 로직 80:20 독립 추첨 여부 등 업무 검증 후 활성화
